🔄 Встроенный ротационный шлюз Порт 8081

Любой ваш скрипт, браузер или парсер может подключиться к http://localhost:8081 как к обычному прокси. Шлюз автоматически перенаправит трафик через живые узлы из пула с авто-ротацией и мгновенным обходом сбоев.

Примеры подключения в 1 клик

cURL:

curl -x http://localhost:8081 https://api.ipify.org?format=json

Python (Requests / Httpx):

import requests proxies = {"http": "http://localhost:8081", "https": "http://localhost:8081"} resp = requests.get("https://api.ipify.org?format=json", proxies=proxies, timeout=10) print(resp.json())

Node.js (Axios):

import axios from 'axios'; import { HttpsProxyAgent } from 'https-proxy-agent'; const agent = new HttpsProxyAgent('http://localhost:8081'); const { data } = await axios.get('https://api.ipify.org?format=json', { httpsAgent: agent }); console.log(data);
